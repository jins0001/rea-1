# Q1. REA는 미국 정부기관이 공개한 건가요?

**답: 아닙니다.** REA는 개인 개발자가 만든 프로젝트입니다.

## 근거

| 확인한 것 | 결과 |
| --- | --- |
| 만든 사람 | `morluto`. GitHub에서 **개인(User) 계정**이고, 회사나 기관 소속이 아님 |
| 저작권 | LICENSE 파일: `Copyright (c) 2026 morluto` |
| 함께 만든 사람 | morluto(약 1,800번 기여), N0zoM1z0, kaoru0822-kitauji 등 개인 개발자들 |
| 저장소에 직접 쓰인 문구 | "REA is not affiliated with or endorsed by the NSA." (`THIRD_PARTY_NOTICES.md`) = **REA는 NSA와 관계없고, NSA가 보증한 것도 아님** |

## 왜 헷갈릴까요? → Ghidra 때문

REA가 연결해서 쓰는 분석 도구 중 하나인 **Ghidra(기드라)** 는 실제로
**미국 국가안보국(NSA)** 이 만들어서 2019년에 무료로 공개한 프로그램입니다.

```
REA (개인 개발자가 만듦)
 └── 연결해서 쓰는 도구들
      ├── Ghidra  ← 미국 NSA가 만들어 공개 ✅ 정부기관
      ├── Hopper  ← 회사가 파는 상용 프로그램
      └── IDA     ← 회사(Hex-Rays)가 파는 상용 프로그램
```

> **비유:** 내가 만든 요리 앱이 "정부 공식 영양 정보"를 가져다 쓴다고 해서,
> 그 앱이 정부가 만든 앱이 되는 건 아닌 것과 같습니다.

# Q5. REA는 내 노트북에서 어떻게 동작하나요? 모든 언어가 되나요?

(2026-10-17에 노트북을 직접 확인한 결과입니다. 아무것도 설치하지 않고 **확인만** 했습니다.)

## 1. 내 노트북 상태

| 항목 | 내 노트북 | REA가 원하는 것 | 결과 |
| --- | --- | --- | --- |
| 운영체제 | Windows 11 64비트 | Windows 10 이상 x64 | ✅ |
| CPU / 메모리 | Ryzen 7 5800H / 28GB | — | ✅ 넉넉함 |
| 디스크 형식 | C:, D: 모두 NTFS | NTFS | ✅ |
| Node.js | v24.19.0 | 24.11 이상 | ✅ |
| npm | 11.17.0 | 있으면 됨 | ✅ |
| Java (JDK) | Temurin JDK 21 (javac 있음) | Ghidra용 JDK 21 이상 | ✅ |
| Python | 3.14.7 | 필수 아님 | ✅ |
| Chrome / Edge | 둘 다 있음 | 웹사이트 분석용 | ✅ |
| AI 에이전트 | Claude Code (VS Code 확장) | MCP 지원 에이전트 | ✅ |
| **Ghidra** | **없음** | .exe 깊은 분석용 | ❌ 따로 설치 필요 |
| REA 자체 | 아직 설치 안 됨 | `npx rea-agents setup` | ⏳ |
| adb / JADX | 없음 | 안드로이드 분석용 | 필요할 때만 |

→ **기본 준비는 거의 다 되어 있습니다.** `.exe` 분석까지 하려면 Ghidra만 더 있으면 됩니다.
(Hopper는 Windows에서 설치 불가 — 맥/리눅스용)

## 2. 내 노트북에서 REA가 동작하는 순서

```text
 ① 나: VS Code에서 Claude Code에게 질문
        "이 앱의 검색 기능이 어떻게 동작하는지 조사해 줘"
          │
 ② Claude Code ──(MCP: 정해진 대화 규칙)──▶ ③ REA (Node.js로 내 노트북에서 실행)
                                                │
                     ┌──────────────────────────┼──────────────────────────┐
                     ▼                          ▼                          ▼
              JS/.NET/Go 파일           .exe / .dll 파일              웹사이트
              REA가 직접 읽음        Ghidra(Java)를 몰래 띄워 분석    Chrome을 띄워 관찰
                     └──────────────────────────┼──────────────────────────┘
                                                ▼
 ④ REA: "알아낸 것 + 근거 + 모르는 것" 정리해서 돌려줌
          │
 ⑤ Claude Code: 나에게 설명하거나, 그걸 바탕으로 코드 작성
```

### 중요한 점

- 분석은 **전부 내 노트북 안에서** 일어납니다. 분석 대상 파일을 인터넷에 올리지 않습니다.
- 단, 분석 **결과**는 Claude(AI)에게 전달됩니다.
- 대부분 **읽기만** 하고, 대상 프로그램을 고치지 않습니다.
- 설치할 때는 바꿀 내용을 먼저 보여 주고 **허락을 받은 뒤** 설정 파일을 수정합니다(기존 설정은 백업).

> **비유:** Claude Code는 **반장**, REA는 **심부름꾼**, Ghidra·Chrome은 **실험 도구**입니다.
> 반장이 "이거 알아 와" 하면, 심부름꾼이 과학실 도구를 꺼내 실험하고 결과 보고서를 가져옵니다.

## 3. 모든 언어가 되나요? → **아니요, 언어마다 다릅니다**

REA는 "프로그래밍 언어"보다 **완성된 파일의 종류**를 기준으로 분석합니다.

### 내 노트북(Windows)에서 되는 것

| 원래 만든 언어 | 파일 예시 | 내 노트북에서 | 필요한 것 | 결과 수준 |
| --- | --- | --- | --- | --- |
| JavaScript / TypeScript | Electron 앱(VS Code, Notion 등), `.asar` | ✅ 바로 가능 | 없음 | ⭐⭐⭐ 아주 잘 됨 |
| 웹사이트 (HTML/JS) | 인터넷 페이지 | ✅ 바로 가능 | Chrome (있음) | ⭐⭐⭐ |
| C# / VB.NET / F# (.NET) | `.exe`, `.dll` | ✅ 바로 가능 | 없음 | ⭐⭐⭐ 원래 코드와 꽤 가까움 |
| Go | `.exe` | ✅ 바로 가능 | 없음 | ⭐ 빌드 정보만 (버전, 사용 모듈) |
| C / C++ / Rust / Delphi 등 | `.exe`, `.dll` | ⚠️ 실험 단계 | **Ghidra 설치** | ⭐⭐ 대략적인 코드 모양 |
| Java / Kotlin (안드로이드) | `.apk` | ⚠️ 가능 | JADX + JDK | ⭐⭐⭐ |
| Dart (Flutter 앱) | `.apk` | ✅ | 없음 | ⭐ 버전·지문 정보만 |
| WebAssembly | `.wasm` | ⚠️ | WABT 도구 | ⭐⭐ |

### 내 노트북에서는 안 되는 것 (리눅스·맥 전용)

| 대상 | 이유 |
| --- | --- |
| 맥 앱 (Swift, Objective-C) 깊은 분석 | Hopper가 맥/리눅스 전용 |
| 리눅스 프로그램(ELF), 크래시 기록 | 리눅스 x64 전용 |
| 블록체인 코드(EVM / Solidity) | 리눅스 x64 전용 |
| 펌웨어, 패킷·신호 기록 | 리눅스 전용 |
| 프로그램 실행 과정 녹화 | 리눅스/맥 전용 |

> 리눅스 전용 기능은 Windows의 **WSL**(윈도우 안의 리눅스)을 쓰면 쓸 수 있을 수도 있지만, 공식 안내는 없습니다.

### 전용 기능이 없는 것

| 언어 | 상황 |
| --- | --- |
| Python (PyInstaller로 만든 `.exe`) | 전용 기능 없음. Ghidra로 `.exe`를 보면 Python 엔진만 보이고 원래 Python 코드는 잘 안 보임 |
| 일반 Java 프로그램 (`.jar`) | 안드로이드 외에는 전용 기능 없음 |

## 4. 왜 언어마다 결과가 다른가요?

| 종류 | 비유 | 분석 난이도 |
| --- | --- | --- |
| JavaScript | 레시피를 **조금 구겨서** 넣어 둔 것 | 쉬움 — 거의 그대로 읽힘 |
| C# (.NET), Java | 레시피를 **요약 메모**로 바꿔 둔 것 | 중간 — 원래 코드와 꽤 비슷하게 복원 |
| C / C++ / Rust | 레시피를 **완성된 케이크로** 구워 버린 것 | 어려움 — 케이크를 보고 재료를 추측해야 함 |

## 5. 해 보고 싶다면 (아직 실행 안 함)

```powershell
# 1단계: Claude Code에 REA 연결 (바꿀 내용을 보여 주고 허락을 물어봄)
npx rea-agents setup

# 2단계(선택): .exe 분석까지 하려면 Ghidra 12.1.x 를 직접 받아서 압축 풀기
#   https://github.com/NationalSecurityAgency/ghidra/releases
```

첫 연습 대상 추천: **유튜브 실험에 쓰인 Serpent 앱** (<https://github.com/dolag233/Serpent>, MIT 라이선스 Electron 앱)
→ 원본 소스가 공개되어 있어서, REA가 알아낸 내용이 맞는지 **정답과 비교**까지 해 볼 수 있습니다.

> ⚠️ 내 노트북에 깔린 **VS Code는 연습 대상으로 부적합**합니다.
> 소스 코드는 MIT로 공개되어 있지만, 마이크로소프트가 배포하는 설치판은 **별도 약관**이 붙어 있고 그 약관이 리버스 엔지니어링을 금지합니다.

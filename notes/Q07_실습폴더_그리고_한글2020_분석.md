## 2. 한글 2020을 분석할 수 있나요?

**답: 하지 않겠습니다.**

| 이유 | 설명 |
| --- | --- |
| 상용 프로그램 | 한글 2020은 한컴이 파는 상용 프로그램이고, 사용권 계약이 따로 있습니다 |
| 약관 | 상용 소프트웨어 약관은 보통 리버스 엔지니어링을 금지합니다 |
| 저작권법 | 한국 저작권법 제101조의4는 호환에 꼭 필요한 정보를 얻는 경우만 아주 좁게 허용합니다 |
| REA 규칙 | REA의 DISCLAIMER는 "남의 소프트웨어를 베끼는 것"을 돕지 않는다고 적어 두었습니다 |

> 엑셀(Q03)과 같은 이유입니다. **내 것이거나, 공개 라이선스이거나, 허락받은 것**만 분석합니다.

## 3. 한글 파일(.hwp)을 다루는 프로그램을 만들고 싶다면 → 리버싱이 필요 없습니다

| 방법 | 설명 |
| --- | --- |
| 공개된 파일 형식 문서 | 한컴이 HWP 파일 형식 문서를 공개해 두었습니다 |
| HWPX | 새 형식(.hwpx)은 XML 기반의 국가 표준(OWPML)입니다 |
| 오픈소스 라이브러리 | pyhwp(Python), hwplib(Java), hwp.js(JavaScript) 같은 공개 프로젝트가 있습니다 |
| 한컴 공식 자동화 기능 | 한글 프로그램을 스크립트로 조종하는 공식 개발 도구가 있습니다 |

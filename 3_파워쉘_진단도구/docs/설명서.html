💡 1. 원리 — 맥가이버 칼(스위스 아미 나이프)에 빗대어 보는 파워쉘

파워쉘(PowerShell)은 윈도우를 설치하면 처음부터 들어 있는 만능 도구함입니다. 파이썬이나 다른 프로그램을 새로 깔 수 없는 컴퓨터(학교 컴퓨터, 친구 컴퓨터)에서도 클릭 한 번으로 똑같이 작동합니다.

🧰 왜 순수 파워쉘인가요?

윈도우 커널(운영체제의 심장부)과 직통으로 연결되어 있어서 가장 가볍고, 가장 빠르고, 가장 정확합니다. 컴퓨터가 켜진 상태라면 아무런 준비 없이 즉시 하드웨어 건강 상태를 뽑아낼 수 있습니다.

⚙️ 2. 작동 원리 — 파워쉘의 마법 주문 3가지

# 1. 꽂혀 있는 디스크가 SSD인지 HDD인지 물어보기
Get-PhysicalDisk

# 2. 메인보드 램 슬롯에 몇 GB짜리 메모리가 꽂혀 있는지 물어보기
Get-CimInstance Win32_PhysicalMemory

# 3. 윈도우가 실제 사용 중인 메모리 용량 물어보기
Get-CimInstance Win32_OperatingSystem

이 마법 주문 세 줄이면 윈도우가 알아서 메인보드 칩셋과 SSD 컨트롤러에게 무전기를 쳐서 결과를 받아옵니다.

📁 3. 구성 — 어떤 파일들로 이루어져 있나요?

파일명 역할 설명
run.bat 원클릭 실행기 더블 클릭만 하면 검은 터미널에서 진단하고 브라우저 보고서까지 열어줍니다.
Analyze-Hardware.ps1 파워쉘 진단 스크립트 SSD, HDD, RAM을 진단하고 HTML 보고서를 파일로 만드는 메인 코드입니다.
Hardware_Diagnostic_Report.html 완성된 진단 보고서 진단이 끝나면 자동으로 만들어지는 단독 실행 웹 리포트입니다.
docs/README.md 마크다운 설명서 프로젝트의 배경과 상세 해설을 담은 문서입니다.
docs/설명서.html 웹 설명서 지금 보고 있는 바로 이 안내 문서입니다.

🔄 4. 프로세스 — 4단계 진단 흐름

1

시스템 센서 및 하드웨어 조회

Get-PhysicalDisk와 Win32_PhysicalMemory를 실행하여 장착된 하드웨어 목록을 가져옵니다.

2

터미널 즉시 컬러 출력

화면에 녹색 Healthy 배지와 사용률 막대그래프를 즉시 출력하여 상태를 보여줍니다.

3

HTML 보고서 파일 자동 생성

표와 통계 카드가 담긴 Hardware_Diagnostic_Report.html 파일을 현재 폴더에 저장합니다.

4

브라우저 자동 팝업

Start-Process를 통해 브라우저가 자동으로 뜨며 멋진 최종 진단서를 확인할 수 있습니다.

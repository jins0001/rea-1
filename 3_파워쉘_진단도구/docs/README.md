# 🛡️ [프로젝트 3] 순수 파워쉘(PowerShell) 하드웨어 진단 도구 설명서

> **대상 독자:** 프로그램 설치 없이 윈도우 기본 기능으로 PC를 진단하고 싶은 중학생 및 초심자  
> **핵심 주제:** 파이썬도, 웹서버도 필요 없다! 윈도우 내장 기능(PowerShell)만으로 SSD/HDD/RAM 분석하고 HTML 보고서 뽑기  
> **실행 파일:** [run.bat](../run.bat) (더블 클릭) 또는 `powershell -File Analyze-Hardware.ps1`

---

## 1. 💡 쉬운 비유로 이해하는 파워쉘의 원리

파워쉘(PowerShell)은 컴퓨터계의 **'스위스 아미 나이프(맥가이버 칼)'**입니다!

```text
┌─────────────────────────────────────────────────────────────┐
│                  윈도우 11 기본 장착 도구함                 │
│                                                             │
│   [ 🧰 파워쉘 (PowerShell) ]                                │
│    별도 다운로드 0개! 윈도우가 태어날 때부터 갖고 있는 만능 도구    │
│                                                             │
│   [ 🔍 WMI / CIM 돋보기 ] ──▶ [ 📄 HTML 리포트 자동 인쇄 ]  │
│    부품 칩셋에 바로 질문          진단 결과를 브라우저 보고서로 발행   │
└─────────────────────────────────────────────────────────────┘
```

| 도구 | 맥가이버 칼 비유 | 장점 |
| --- | --- | --- |
| **순수 파워쉘** | **기본 내장 나이프** | 친구 집 컴퓨터, 학교 실습실 PC 등 파이썬이 안 깔린 컴퓨터에서도 즉시 100% 작동합니다. |
| **WMI/CIM 엔진** | **확대경** | 윈도우 커널 수준에서 메인보드 칩셋과 직접 통신하므로 어떤 외부 프로그램보다 속도가 빠르고 정확합니다. |
| **자동 HTML 보고서** | **인쇄된 진단 성적표** | 진단이 끝나면 브라우저로 볼 수 있는 예쁜 진단서(`Hardware_Diagnostic_Report.html`)를 자동으로 뽑아줍니다. |

## 2. ⚙️ 파워쉘은 어떻게 정보를 수집할까? (명령어 원리)

파워쉘은 마우스 클릭 없이 키보드 한 줄로 윈도우의 모든 부품을 관리할 수 있습니다:

```powershell
# 1. 꽂혀 있는 디스크가 SSD인지 HDD인지 물어보기
Get-PhysicalDisk

# 2. 메인보드 램 슬롯에 몇 GB짜리 메모리가 꽂혀 있는지 물어보기
Get-CimInstance Win32_PhysicalMemory

# 3. 윈도우가 사용 중인 실제 메모리 용량 물어보기
Get-CimInstance Win32_OperatingSystem
```

## 4. 🔄 4단계 프로세스 (처리 흐름)

```text
[1단계] WMI 센서 조회 ──▶ [2단계] 터미널 컬러 출력 ──▶ [3단계] HTML 보고서 파일 작성 ──▶ [4단계] 브라우저 자동 실행
윈도우 내장 명령 실행     글자 색상 입혀 즉시 확인      표와 디자인 태그로 파일 저장        진단 리포트 감상
```

1. **1단계 (센서 조회):** 운영체제 이름, 장착된 SSD 디스크 2개, 듀얼 채널 RAM 슬롯을 조회합니다.
2. **2단계 (터미널 컬러 출력):** 정상 상태는 초록색(● Healthy), SSD는 하늘색([SSD])으로 알록달록하게 보여줍니다.
3. **3단계 (HTML 보고서 조립):** 수집된 결과를 깔끔한 CSS 스타일이 들어간 웹 문서(`Hardware_Diagnostic_Report.html`)로 기록합니다.
4. **4단계 (브라우저 자동 오픈):** 사용자가 직접 파일을 찾아 누를 필요 없이 바로 브라우저가 열리며 진단 결과가 화면에 뜹니다.

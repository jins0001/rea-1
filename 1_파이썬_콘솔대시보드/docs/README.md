# 🖥️ [프로젝트 1] 파이썬 하드웨어 콘솔 대시보드 설명서

> **대상 독자:** 컴퓨터 구조가 궁금한 중학생 및 초심자  
> **핵심 주제:** 파이썬(Python)으로 내 PC의 SSD, HDD, RAM(메모리) 상태를 실시간 분석하기  
> **실행 파일:** [run.bat](../run.bat) (더블 클릭) 또는 `python src/analyzer.py`

---

## 1. 💡 쉬운 비유로 이해하는 부품의 원리

컴퓨터를 **공부방**에 비유하면 아주 이해하기 쉽습니다!

```text
┌─────────────────────────────────────────────────────────────┐
│                       내 컴퓨터 방                           │
│                                                             │
│   [ 🧠 CPU ]             [ 📖 RAM (메모리) ]                 │
│    공부하는 학생              공부할 때 책을 펴놓는 '넓은 책상'        │
│                                                             │
│   [ ⚡ SSD (초고속) ]     [ 💾 HDD (대용량) ]                │
│    손 바로 닿는 책꽂이         방 구석 큰 보관 창고                  │
└─────────────────────────────────────────────────────────────┘
```

| 컴퓨터 부품 | 우리 생활 비유 | 역할과 특징 |
| --- | --- | --- |
| **RAM (메모리)** | **공부 책상** | 책상이 넓을수록 여러 책(프로그램)을 한꺼번에 펼쳐놓고 빠르게 공부할 수 있습니다. (내 PC는 약 28GB로 아주 넓은 대형 책상입니다!) 전원이 꺼지면 책상 위는 깨끗이 지워집니다. |
| **SSD (반도체 저장소)** | **초고속 책꽂이** | 모터나 회전 부품 없이 반도체 칩에 전자로 저장하여 빛의 속도로 책을 꺼냅니다. (현재 내 PC에 2개 장착: 256GB, 500GB) |
| **HDD (하드디스크)** | **레코드판 창고** | 둥근 자석 디스크가 윙~ 돌면서 바늘(헤드)로 데이터를 읽습니다. 용량 대비 저렴하지만 모터가 돌기 때문에 SSD보다 속도가 느립니다. |

## 2. ⚙️ 어떻게 프로그램이 하드웨어를 알아낼까? (작동 원리)

파이썬 프로그램이 직접 메인보드를 돋보기로 들여다보는 것이 아닙니다!  
**윈도우(Windows 11) 운영체제 안에 있는 "만능 비서(WMI / CIM)"**에게 정중하게 물어보는 방식입니다.

```text
[ 🐍 파이썬 대시보드 ]
        │  "비서님! 지금 꽂혀 있는 디스크랑 메모리 상태 좀 알려주세요!"
        ▼
[ 🏢 윈도우 WMI / CIM 시스템 서비스 ]
        │  하드웨어 센서와 컨트롤러 확인
        ▼
[ 📊 실시간 수치 데이터 수집 ] ──▶ [ JSON 형태로 파이썬 전달 ] ──▶ [ 예쁜 컬러 게이지 화면 출력 ]
```

1. **WMI / CIM 인터페이스:** 윈도우가 메인보드, 칩셋, 드라이브 컨트롤러와 24시간 대화하며 기록해 둔 시스템 정보 보관소입니다.
2. **비밀 질문 명령어:**
   - 디스크 상태: `Get-PhysicalDisk` (SSD인지 HDD인지, 고장 징후가 있는지 확인)
   - 메모리 상태: `Win32_OperatingSystem`, `Win32_PhysicalMemory` (전체 메모리, 슬롯별 제조사와 클럭 속도)
   - 실시간 속도: `Win32_PerfFormattedData_PerfDisk_PhysicalDisk` (지금 초당 몇 MB를 읽고 쓰는지)

## 3. 📁 프로그램 구성 (폴더 및 파일)

```text
1_파이썬_콘솔대시보드/
├── run.bat               ← 더블 클릭하면 검은 창에서 바로 실행되는 배치 파일
├── run.ps1               ← 파워쉘용 실행 스크립트
├── src/
│   └── analyzer.py       ← 4개 부품을 실시간 조회·계산·출력하는 파이썬 메인 코드
└── docs/
    ├── README.md         ← 지금 읽고 있는 중학생 눈높이 마크다운 설명서
    └── 설명서.html       ← 브라우저로 예쁘게 볼 수 있는 웹 문서
```

### 소스 코드의 핵심 역할
* `run_ps_json(cmd)`: 윈도우 비서에게 명령을 보내고 결과를 깔끔한 파이썬 데이터(JSON)로 변환합니다.
* `get_hardware_info()`: SSD/HDD, 남은 용량, 메모리 슬롯, 실시간 읽기/쓰기 속도를 종합 수집합니다.
* `make_bar(percent)`: `[■■■■■■■■          ] 50%` 와 같이 한눈에 보이는 컬러 막대그래프를 만듭니다.
* `print_dashboard(info)`: 수집된 모든 하드웨어 지표를 깔끔한 터미널 카드로 그려줍니다.

## 4. 🔄 4단계 프로세스 (처리 과정)

```text
[1단계] 하드웨어 감지  ──▶  [2단계] 데이터 가공  ──▶  [3단계] 건강 진단  ──▶  [4단계] 화면 갱신
Get-PhysicalDisk           바이트(B)를 GB로          HealthStatus=OK?         3초마다 화면을 지우고
RAM 슬롯 조회               사용률(%) 백분율 계산     여유 공간 넉넉한가?       최신 상태로 다시 그리기
```

1. **1단계 (하드웨어 감지):** 내 PC에 장착된 물리 디스크(NVMe SSD) 2개와 메모리 카드 2장을 감지합니다.
2. **2단계 (데이터 가공):** 사람이 읽기 어려운 `17,179,869,184 바이트` 숫자를 `16.0 GB` 단위로 알기 쉽게 변환합니다.
3. **3단계 (건강 진단):** `Healthy(정상)` 여부와 디스크 여유 공간이 위험 수준인지 점검합니다.
4. **4단계 (화면 갱신):** `cls` 명령어로 화면을 새로고침하며 3초마다 디스크 속도와 램 사용량을 실시간 보여줍니다.

내 컴퓨터의 SSD, HDD, RAM(메모리) 상태를 터미널에서 실시간으로 분석하기

💡 1. 원리 — 방과 가구에 빗대어 보는 컴퓨터 부품

컴퓨터를 우리들의 공부방이라고 생각하면 정말 쉽게 이해할 수 있습니다!

📖

RAM (메모리) = 공부 책상

공부할 때 책과 노트를 펼쳐놓는 공간입니다. 책상이 넓을수록(내 PC: 28GB) 한 번에 여러 개의 게임과 인터넷 창을 띄워도 버벅거리지 않습니다.

⚡

SSD = 초고속 전자 책꽂이

움직이는 모터 부품 없이 순수 반도체 칩에 전자로 기록합니다. 손만 뻗으면 빛의 속도로 게임 데이터를 바로 꺼내옵니다.

💾

HDD = 거대한 자석 창고

동그란 LP판 같은 자석 디스크가 윙~ 돌면서 바늘로 읽습니다. 용량에 비해 값이 싸지만 물리적으로 돌기 때문에 SSD보다 속도가 느립니다.

⚙️ 2. 작동 원리 — 파이썬은 어떻게 부품 정보를 알아낼까?

파이썬 프로그램이 직접 컴퓨터 본체를 열고 돋보기로 부품을 들여다보는 게 아닙니다. 윈도우(Windows 11) 안에는 부품들의 상태를 24시간 꼼꼼히 적어두는 시스템 비서(WMI/CIM)가 살고 있습니다. 

[파이썬 프로그램] ──▶ "비서님! 지금 디스크랑 메모리 건강 상태 좀 알려주세요!"
       │
[윈도우 비서 (WMI/CIM)] ──▶ 하드웨어 칩셋 센서 확인
       │
[결과 데이터 (JSON)] ──▶ 바이트를 GB로 계산 후 컬러 그래프로 터미널에 출력!

📁 3. 구성 — 어떤 파일들로 이루어져 있나요?

파일명 역할 설명
run.bat 원클릭 실행기 더블 클릭만 하면 검은색 터미널 창을 띄우고 바로 분석을 시작합니다.
src/analyzer.py 파이썬 메인 두뇌 윈도우 시스템에 질문을 던져 SSD/HDD/RAM 수치를 가져와 그래프를 그립니다.
docs/README.md 텍스트 설명서 깃허브나 코드 에디터에서 바로 읽을 수 있는 마크다운 안내서입니다.
docs/설명서.html 웹 설명서 지금 보고 있는 바로 이 아름다운 브라우저용 안내서입니다.

🔄 4. 프로세스 — 프로그램이 실행되는 4단계 과정

1

하드웨어 감지 (Hardware Detection)

내 PC에 꽂힌 물리 디스크(NVMe SSD)들과 램 슬롯에 몇 장의 메모리가 꽂혀 있는지 조회합니다.

2

데이터 가공 및 단위 변환 (Data Processing)

컴퓨터가 좋아하는 거대한 바이트(Bytes) 숫자를 사람이 읽기 쉬운 기가바이트(GB)와 퍼센트(%)로 변환합니다.

3

건강 상태 및 수명 점검 (Health Diagnostic)

디스크 건강 상태(HealthStatus)가 Healthy(정상)인지, 여유 공간이 부족한지 분석합니다.

4

실시간 컬러 화면 출력 (Real-time Rendering)

3초마다 화면을 깨끗이 지우고 최신 디스크 읽기/쓰기 속도와 램 사용량을 막대그래프로 보여줍니다.

🔬 5. 실제 내 PC 분석 예시 (실측 데이터)

내 컴퓨터에서 실제로 프로그램을 실행했을 때 확인된 진짜 하드웨어 스펙입니다:

부품 모델명 / 사양 종류 / 연결 건강 상태
디스크 #1 WDC PC SN530 256GB SSD (NVMe) Healthy (정상)
디스크 #0 Samsung SSD 970 EVO Plus 500GB SSD (NVMe) Healthy (정상)
메모리 1번 Samsung 16GB (2667 MHz) DDR4 모듈 정상 동작
메모리 2번 호환 메모리 16GB (3200 MHz) DDR4 모듈 정상 동작

💡 총평: 구형 저속 HDD가 전혀 없고, 두 드라이브 모두 최신 고속 NVMe M.2 SSD이며, 램도 16GB 2장(총 32GB, 시스템 가용 28GB)으로 넉넉하게 세팅된 아주 훌륭한 고성능 PC입니다!

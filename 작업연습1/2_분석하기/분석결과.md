## 3. 함수마다 하는 일

### `Average`

- 입력: 정수 묶음(배열) → 출력: 실수(소수점 숫자)
- 명령어 32개
- 비교에 쓰는 숫자 (나오는 순서대로): 없음
- 쓰는 글자 (나오는 순서대로): 없음
- 부르는 함수: 없음
- 나눗셈(div)이 있음 → 평균 계산으로 추정

### `LetterFor`

- 입력: 실수(소수점 숫자) → 출력: 글자
- 명령어 22개
- 비교에 쓰는 숫자 (나오는 순서대로): 90, 80, 70, 60
- 쓰는 글자 (나오는 순서대로): "A", "B", "C", "D", "F"
- 부르는 함수: 없음
- 결과를 돌려주는 곳(ret)이 5군데 → 조건에 따라 일찍 끝나는 길이 여러 개

### `Grade`

- 입력: 정수 묶음(배열) → 출력: 글자
- 명령어 63개

- 쓰는 글자 (나오는 순서대로): "F", "+"
- 부르는 함수: Average, LetterFor, Concat
- 결과를 돌려주는 곳(ret)이 3군데 → 조건에 따라 일찍 끝나는 길이 여러 개

## 5. 추리 (가설)

| 단서 | 추리 |
| --- | --- |
| `LetterFor`: 숫자 90, 80, 70, 60 / 글자 "A","B","C","D","F" | 평균이 90↑ A, 80↑ B, 70↑ C, 60↑ D, 나머지 F |
| `Grade`: 숫자 40 다음에 바로 "F" | 한 과목이라도 40 미만이면 바로 F (과락) |
| `Grade`: 숫자 95, 글자 "+", `Concat`(글자 붙이기) | 모든 과목이 95 이상이면 등급 뒤에 "+" |
| `Main`: 숫자 100, `TryParse`, 오류 글자 | 입력이 0~100 숫자가 아니면 오류 메시지 |
| `Main`: 글자 "average={0:F1} grade={1}" | 평균은 소수점 한 자리로 출력 |

> 가설은 3단계에서 **원본 exe와 똑같이 동작하는지 시험**해서 확인합니다.

💡 1. 원리 — 식당의 손님과 요리사에 빗대어 보는 웹 구조

웹 브라우저와 파이썬 서버가 일하는 방식은 맛있는 레스토랑과 완벽히 똑같습니다!

🍽️

손님 = 웹 브라우저 (Chrome, Edge)

식탁에 앉아서 2초마다 "지금 메모리랑 SSD 상황 어때요?" 하고 벨을 누릅니다. 주방에서 보낸 데이터를 예쁜 원형 차트와 네온 빛으로 화려하게 차려냅니다.

👨‍🍳

요리사 = 파이썬 서버 (`server.py`)

주방에서 윈도우(WMI) 창고로 달려가 SSD 수명, 램 사용량을 확인한 다음, 먹기 좋은 형태(JSON 데이터)로 요리하여 손님에게 배달합니다.

⚙️ 2. 작동 원리 — 왜 브라우저에 바로 안 나오고 서버를 거칠까?

웹 브라우저는 인터넷 서핑 중에 해킹을 당하지 않도록 컴퓨터 하드웨어 깊숙한 곳을 직접 만질 수 없게 안전장치(샌드박스)가 걸려 있습니다. 그래서 내 컴퓨터 안에 믿을 수 있는 전용 중계 서버(파이썬)를 만들어 브라우저와 시스템 사이를 연결해 주는 것입니다. 

[ 1. 브라우저 ] ──(2초마다 GET /api/hardware 요청)──▶ [ 2. 파이썬 server.py ]
       │                                                         │
[ 4. 원형 게이지 회전 및 수치 갱신 ] ◀──(JSON 수치 배달)── [ 3. 윈도우 WMI 센서 읽기 ]

📁 3. 구성 — 어떤 파일들로 이루어져 있나요?

파일명 역할 설명
run.bat 원클릭 시동기 더블 클릭하면 파이썬 서버를 켜고, 크롬/엣지 브라우저 창을 자동으로 열어줍니다.
server.py 백엔드 웹서버 포트 8080을 열어 웹 파일들을 서빙하고 /api/hardware 통신 창구를 담당합니다.
public/index.html 대시보드 뼈대 원형 게이지, 볼륨 바, 메모리 슬롯 카드의 구조를 잡는 HTML 문서입니다.
public/style.css 비주얼 스타일 반투명 글래스모피즘, 네온 컬러, 원형 게이지 회전 효과를 담당합니다.
public/app.js 프론트엔드 두뇌 2초마다 서버에서 데이터를 받아와 게이지 둘레를 계산하고 화면에 숫자를 채워 넣습니다.

🔄 4. 프로세스 — 4단계 데이터 흐름

1

서버 시작 및 브라우저 열기

파이썬이 8080 포트로 대기하고, 웹 브라우저가 http://localhost:8080에 자동으로 접속합니다.

2

사이버 글래스 UI 렌더링

어두운 밤하늘에 별빛 같은 네온 다크 테마와 부드러운 카드 레이아웃이 화면에 깔끔하게 나타납니다.

3

비동기 통신 (Fetch)

화면 깜빡임 없이 조용히 2초마다 윈도우 시스템의 최신 RAM 사용량과 SSD 읽기/쓰기 속도를 긁어옵니다.

4

실시간 게이지 애니메이션

원형 SVG 바가 68% 지점까지 부드럽게 채워지고, 초록색 정상 신호등(Healthy)이 반짝입니다.

🔬 5. 실제 내 PC 화면에 표시되는 데이터 예시

실제 내 컴퓨터에서 웹 대시보드를 띄웠을 때 브라우저에 나타나는 지표입니다:

영역 지표 내용 실측 수치 해석
RAM 원형 게이지 사용률 및 잔여 공간 68.1% (27.86 GB 중 18.97 GB 사용) 8.89 GB 여유로 다중 작업에 충분함
물리 저장소 NVMe SSD 2장 구성 WDC 256GB + Samsung 500GB 고장 없는 Healthy (정상) 상태
RAM 슬롯 듀얼 채널 슬롯 구성 16GB (2667MHz) + 16GB (3200MHz) 총 32GB 물리 장착 완료
볼륨 파티션 C:, D:, E: 드라이브 C(109GB 여유), E(80GB 여유) 파란색 프로그레스 바로 쾌적함 표시

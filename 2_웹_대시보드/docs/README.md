# 🌐 [프로젝트 2] PC 하드웨어 실시간 웹 대시보드 설명서

> **대상 독자:** 코딩과 웹 기술에 호기심 많은 중학생 및 초보자  
> **핵심 주제:** 웹 브라우저(크롬·엣지)에서 게이지와 화려한 그래픽으로 내 PC 하드웨어 실시간 관찰하기  
> **실행 파일:** [run.bat](../run.bat) (더블 클릭) 또는 `python server.py`

---

## 1. 💡 쉬운 비유로 이해하는 웹 대시보드의 원리

웹 브라우저와 파이썬 서버의 관계를 **멋진 패밀리 레스토랑**에 비유해 볼까요?

```text
┌─────────────────────────────────────────────────────────────┐
│                       패밀리 레스토랑                        │
│                                                             │
│   [ 🍽️ 손님 (웹 브라우저) ]     ──2초마다 주문──▶ [ 👨‍🍳 주방장 (파이썬 서버) ]
│    크롬이나 엣지로 화면을 봄                          server.py
│                                                             │
│   [ 🎨 화려한 접시 세팅 ]       ◀──맛있는 음식─── [ 📦 윈도우 재료 창고 (WMI) ]
│    index.html, CSS, JS              (JSON 데이터)     SSD/RAM 센서 값
└─────────────────────────────────────────────────────────────┘
```

| 구성 요소 | 레스토랑 비유 | 실제 컴퓨터 역할 |
| --- | --- | --- |
| **웹 브라우저 (Chrome, Edge)** | **식탁에 앉은 손님** | 모니터 화면에 게이지 차트와 반짝이는 네온 그래픽을 시각적으로 보여줍니다. |
| **파이썬 서버 (`server.py`)** | **주방의 총괄 요리사** | 윈도우 창고에서 SSD 수명, 메모리 사용량을 꺼내와 예쁜 그릇(JSON)에 포장해 손님에게 전달합니다. |
| **API (`/api/hardware`)** | **주문서와 음식 엘리베이터** | 브라우저가 2초마다 "지금 하드웨어 상태 어때요?" 하고 묻는 비밀 통로입니다. |

## 2. ⚙️ 어떻게 브라우저가 내 컴퓨터 부품을 알 수 있을까? (동작 원리)

보통 웹 브라우저는 보안 때문에 내 컴퓨터 하드웨어 깊은 곳을 직접 만질 수 없습니다.  
그래서 **내 컴퓨터 안에서 작은 로컬 웹 서버(`server.py`)**를 띄우는 것이 핵심 기술입니다!

```text
[ 1. 브라우저 시작 ] ──▶ http://localhost:8080 접속
       │
[ 2. 화면 구성품 다운로드 ] ──▶ HTML(뼈대), CSS(스타일), JS(동작) 받아옴
       │
[ 3. 2초 주기 대화 ] ──▶ fetch('/api/hardware') 요청 전송
       │
[ 4. 파이썬의 시스템 진단 ] ──▶ 윈도우 WMI로부터 SSD 2개, RAM 28GB 정보 수집
       │
[ 5. 실시간 시각화 ] ──▶ SVG 원형 게이지가 슝~ 돌며 68% 사용량 표시!
```

## 3. 📁 프로그램 구성 (폴더 및 파일)

```text
2_웹_대시보드/
├── run.bat               ← 더블 클릭하면 서버 켜고 브라우저까지 자동으로 열어주는 실행 파일
├── run.ps1               ← 파워쉘용 실행기
├── server.py             ← 파이썬 내장 경량 웹 서버 + 하드웨어 API 엔드포인트
├── public/               ← 브라우저가 읽는 웹 프론트엔드 파일 모음
│   ├── index.html        ← 대시보드 화면 구조 (카드, 원형 게이지, 표)
│   ├── style.css         ← 사이버 다크 모드 & 글래스모피즘 네온 디자인
│   └── app.js            ← 2초마다 데이터를 가져와 화면을 애니메이션하는 자바스크립트
└── docs/
    ├── README.md         ← 지금 읽고 있는 중학생 눈높이 마크다운 설명서
    └── 설명서.html       ← 브라우저로 보는 화려한 웹 설명서
```

## 4. 🔄 4단계 프로세스 (처리 흐름)

1. **서버 기동 및 브라우저 호출:**  
   `server.py`를 실행하면 포트 8080번을 열고, 윈도우 기본 웹 브라우저를 자동으로 띄워 `http://localhost:8080`으로 연결합니다.
2. **첫 화면 렌더링:**  
   `index.html`과 `style.css`가 로드되어 미래 지향적인 다크 네이비 UI와 글래스모피즘(유리처럼 투명한 카드) 디자인이 펼쳐집니다.
3. **비동기 데이터 통신 (Fetch API):**  
   `app.js`가 화면 새로고침 없이 백그라운드에서 `/api/hardware`에 최신 수치를 요청합니다.
4. **SVG 차트 애니메이션 및 갱신:**  
   받아온 메모리 사용률(예: 68%)에 따라 원형 게이지의 둘레 길이를 부드러운 애니메이션으로 채우고, 디스크 I/O 속도를 표시합니다.

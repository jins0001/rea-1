1. 이 저장소는 누구 것인가요?

jins0001/rea는 직접 만든 프로젝트가 아니라 복사본(포크, fork)입니다.

항목내용

복사본jins0001/rea (2026년 10월 13일에 복사함)
복사본에서 바꾼 것없음 (원본과 똑같은 상태)

포크(fork)란? 친구의 노트를 복사해서 내 공책에 붙여 둔 것과 같습니다. 원본은 그대로 있고, 내 복사본은 내가 마음대로 고칠 수 있어요.

2. REA는 무엇을 하는 도구인가요?

REA는 Reverse Engineer Anything(무엇이든 거꾸로 분석하기)의 줄임말입니다.

리버스 엔지니어링이 뭐예요?

  • 보통 프로그램은 설계도(소스 코드) → 완성품(프로그램) 순서로 만듭니다.
  • 리버스 엔지니어링은 반대로 완성품을 보고 → 어떻게 만들었는지 추측하는 것입니다.
비유: 맛있는 과자를 먹고 "이건 밀가루, 설탕, 버터가 이 정도 들어갔겠다"라고 성분을 알아내는 것과 비슷합니다. 레시피(소스 코드)는 없지만, 과자(프로그램)를 꼼꼼히 살펴서 알아내는 거죠.

REA의 특별한 점: AI 비서와 연결된다

REA는 AI 에이전트(Claude Code, Cursor, Codex 같은 AI 코딩 도우미)가 분석 도구를 쓸 수 있게 이어 주는 "연결 다리"입니다. 이 연결 방식을 MCP라고 부릅니다.

🙋 나질문 → 🤖 AI 에이전트MCP → 🔧 REA→ 🔬 Ghidra · Hopper 등

분석 결과는 거꾸로 돌아와서, AI가 알아낸 것 + 그 근거 + 아직 모르는 것을 정리해 줍니다.

예시 부탁: "메모 앱의 검색 기능이 어떻게 작동하는지 조사하고, 근거를 보여 준 다음, 내 프로젝트에 비슷한 기능을 만들어 줘."

4. 실제 사용 사례

  1. DX-Ball (옛날 벽돌깨기 게임) — 공 위치에 따라 소리가 왼쪽/오른쪽에서 나는 계산을 찾아내 C 언어로 다시 만들었고, 3,205개 테스트를 모두 통과했습니다.
  2. Notion (메모 앱) — "복사/붙여넣기"가 앱 내부에서 어떤 길을 따라 처리되는지 추적했습니다.
  3. TH04 (옛날 슈팅 게임) — 총알이 원 모양으로 퍼지는 각도 계산을 알아냈습니다.

6. 어떻게 써 보나요?

컴퓨터에 Node.js(22.19 이상)가 깔려 있으면 됩니다.

# AI 에이전트에 REA 연결하기
npx rea-agents setup

# 터미널에서 직접 JavaScript 앱 분석하기
npx -y rea-agents@latest analyze-javascript-application "D:/apps/example" --json

깊은 분석(.exe 같은 프로그램)을 하려면 Ghidra(무료), Hopper, IDA 중 하나가 따로 필요합니다.

7. ⚠️ 꼭 지켜야 할 규칙

REA 제작자들은 올바른 용도로만 쓰라고 강조합니다 (DISCLAIMER.md).

✅ 해도 되는 것

  • 보안 연구, 악성코드 분석
  • 공부, 해킹 대회(CTF)
  • 내가 만들었거나 허락받은 프로그램 분석
  • 오래된 소프트웨어 보존

❌ 하면 안 되는 것

  • 게임 핵(치트) 만들기
  • 정품 인증·복사 방지 뚫기
  • 남의 프로그램 코드를 그대로 베끼기
  • 허락 없이 남의 시스템 침입하기
다른 사람의 프로그램을 분석하는 것은 법이나 사용 약관에 따라 금지될 수 있습니다. "내 것이거나, 허락받은 것"만 분석하세요.

8. 질문: "이거 프로그램 개발하는 건가요?"

답: 반은 맞고 반은 다릅니다.

관점설명
REA 자체✅ 프로그램 개발 맞음. TypeScript로 35만 줄을 짠 소프트웨어 프로젝트입니다.
REA로 하는 일🔍 새 프로그램을 만드는 게 아니라, 이미 있는 프로그램을 분석하는 도구입니다.
jins0001/rea📋 원본을 복사만 해 둔 상태라서, 아직 직접 개발한 부분은 없습니다.
  • REA를 "사용" = 분석 작업 (돋보기로 들여다보기)
  • REA를 "고치거나 기능 추가" = 프로그램 개발 (돋보기 자체를 개선하기)
  • REA로 알아낸 걸 내 앱에 넣기 = 내 프로그램 개발에 활용
비유: REA는 "현미경"입니다. 현미경을 만드는 회사는 개발을 하고, 현미경을 쓰는 과학자는 관찰(분석)을 합니다. 지금 저장소는 현미경 설계도를 복사해 온 상태예요.
